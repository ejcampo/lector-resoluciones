1. CARGA Y PROCESAMIENTO INICIAL
   ═════════════════════════════════════════════════════════════════════════
   Cliente (Frontend)          Servidor (PHP/PostgreSQL)
   ─────────────────          ────────────────────────
   
   Selecciona PDFs
          ↓
   POST /api/upload ────────→ Guarda en storage/temp/uploads/
                             ↓
                  POST /api/extract
                             ↓
                  1. Convierte a imágenes
                  2. Ejecuta OCR
                  3. Extrae datos
                  4. INSERT INTO resoluciones_extraidas
                     (confirmado = FALSE, usuario_id = 1)
                             ↓
   ←──────────── Respuesta JSON con resultados
        ↓
   Renderiza tabla
   Habilita botón "Confirmar"


2. CONFIRMACIÓN DE DOCUMENTOS
   ═════════════════════════════════════════════════════════════════════════
   Cliente (Frontend)          Servidor (PHP/PostgreSQL)
   ─────────────────          ────────────────────────
   
   Usuario: [Confirmar Documentos]
        ↓
   POST /api/confirmar ────→ Recibe:
   {                          {
     archivos: [...],           archivos: [Res_001.pdf, Res_002.pdf],
     usuario_id: 1              usuario_id: 1
   }                          }
                             ↓
                    Para cada archivo:
                    UPDATE resoluciones_extraidas
                    SET confirmado = true
                    WHERE archivo = ? AND usuario_id = ?
                             ↓
   ←──────────── Respuesta:
   {                        {
     success: true,           success: true,
     confirmados: 3,          confirmados: 3,
     message: "..."           message: "Se confirmaron 3 documento(s)."
   }                        }
        ↓
   Limpia tabla procesamiento
   Cambia a vista "Confirmados"
   GET /api/resoluciones-confirmadas ────→ SELECT *
                                           WHERE usuario_id = 1
                                           AND confirmado = TRUE
                                                ↓
                                           ←────────────────
   Renderiza tabla de confirmados


3. OBTENER DOCUMENTOS CONFIRMADOS
   ═════════════════════════════════════════════════════════════════════════
   Cliente                     Servidor
   ───────                     ────────
   
   GET /api/resoluciones-confirmadas?usuario_id=1
                        ↓
                SELECT id, archivo, numero_resolucion,
                       primer_parrafo, firmante, imagen_firma, estado
                FROM resoluciones_extraidas
                WHERE usuario_id = 1 AND confirmado = true
                ORDER BY actualizado_en DESC
                        ↓
                ←─────────────────────────
   Renderiza en tabla paginada


╔═══════════════════════════════════════════════════════════════════════════════╗
║                         CONSULTAS SQL CLAVE                                  ║
╚═══════════════════════════════════════════════════════════════════════════════╝


-- 1. Procesar nuevo documento
INSERT INTO resoluciones_extraidas (
  archivo, numero_resolucion, primer_parrafo, firmante, 
  estado, usuario_id, confirmado, imagen_firma
) VALUES (
  'Res_001.pdf', '05285-06-2026', 'La Secretaría...', 'Juan Pérez',
  'OK', 1, FALSE, 'firma_res_001.jpg'
);


-- 2. Confirmar documento
UPDATE resoluciones_extraidas 
SET confirmado = TRUE, actualizado_en = NOW()
WHERE archivo = 'Res_001.pdf' AND usuario_id = 1;


-- 3. Obtener sin confirmar (para vista Procesar)
SELECT * FROM resoluciones_extraidas
WHERE usuario_id = 1 AND confirmado = FALSE
ORDER BY actualizado_en DESC;


-- 4. Obtener confirmados (para vista Confirmados)
SELECT * FROM resoluciones_extraidas
WHERE usuario_id = 1 AND confirmado = TRUE
ORDER BY actualizado_en DESC;


-- 5. Estadísticas
SELECT 
  COUNT(*) FILTER (WHERE confirmado = FALSE) as sin_confirmar,
  COUNT(*) FILTER (WHERE confirmado = TRUE) as confirmados,
  COUNT(*) as total
FROM resoluciones_extraidas
WHERE usuario_id = 1;

   o confirmar


╔═══════════════════════════════════════════════════════════════════════════════╗
║                         CASOS DE USO COMUNES                                 ║
╚═══════════════════════════════════════════════════════════════════════════════╝


CASO 1: Usuario procesa y confirma documentos
────────────────────────────────────────────
1. Carga 3 PDFs
2. Hace clic "Procesar archivos"
3. Sistema convierte, OCR y extrae
4. Ve resultados en tabla (status: OK)
5. Hace clic "Confirmar Documentos"
6. Se guardan como confirmados
7. Cambia a vista "Confirmados"
8. Puede exportar Excel o continuar


CASO 2: Usuario procesa pero revisa antes de confirmar
──────────────────────────────────────────────────
1. Carga 3 PDFs
2. Procesa
3. Revisa datos extraídos
4. Nota un error en el documento #2
5. Hace clic "Cancelar" (quita ese documento de tabla)
6. Carga el PDF corregido y reprocesa
7. Confirma los 3 documentos corregidos


CASO 3: Usuario regresa después de procesar
─────────────────────────────────────────
1. Abre la aplicación (nueva sesión)
2. Inicia sesión
3. Ve pestaña "Confirmados" con sus documentos previos
4. Puede exportar, revisar o procesar más


CASO 4: Múltiples usuarios
─────────────────────────
Juan Pérez:                  María García:
- Procesa 5 docs         - Procesa 3 docs
- Confirma 5             - Confirma 2 (1 en revisión)
- BD: usuario_id=1       - BD: usuario_id=2
                         
Cada usuario ve solo      Completamente separados
sus documentos           en la BD gracias a usuario_id
